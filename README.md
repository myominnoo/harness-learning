# Harness Learning

Learning materials for the Harness AI agent framework.

## Project Structure

```
.
├── agent/           # Agent implementation
├── benchmarks/      # Benchmarking scripts
├── docs/            # Documentation
├── notes/           # Working notes
├── config/          # Configuration files
└── data/            # Generated data
```

## Usage

Run the context selector:
```bash
python3 benchmarks/context_selector.py
```
